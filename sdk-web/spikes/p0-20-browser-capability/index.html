Certivo P0-20: browser capability spike

Page version p0-20-v2. Runs entirely inside your browser. It sends nothing anywhere (its security policy forbids network requests) and stores nothing except a few throw-away test keys that it deletes at the end.

How to use it

  1. Click Run all tests and keep this tab in front until it says Finished (about 30 seconds). Background tabs are slowed down by the browser and give wrong results.
  2. Click Download results and send me the file (or click Copy results and paste it in the chat).
  3. Optional: click Run camera test. It asks permission, reads a few frames to measure speed, then stops the camera. Frames are never saved or sent.
