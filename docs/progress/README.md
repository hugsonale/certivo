# Progress log

One file per month (`YYYY-MM.md`). Add one entry per working session, newest at the bottom. At each phase gate, also save a gate review here.

## Entry template

```
### YYYY-MM-DD
- **Hours:**
- **Steps worked (ID and status change):**
- **What shipped (PR or commit links):**
- **Decisions made (ADR numbers):**
- **Blocked or at risk:**
- **Claims touched:** none | list
- **Next session:**
```

## Phase gate review template

```
# Phase N gate review: YYYY-MM-DD
- Each exit-gate item: pass or fail, with the evidence link
- Open risks and decisions carried forward
- Estimate versus actual (weeks planned, weeks used, why they differ)
- Go or no-go for the next phase, and who decided
```
