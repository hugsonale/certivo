# Browser test results (P0-20)

One JSON file per browser, downloaded from the P0-20 test page
(`sdk-web/spikes/p0-20-browser-capability/`). Keep every file: they are the evidence behind
`docs/spec/browser-support-matrix.md` and ADR 0020.

Files contain only the browser name and version, the operating system name, a coarse CPU core count, and
the pass or fail of each test. They contain no personal data, no video and no keys.

File name pattern: `p0-20-<browser>-<version>-<os>.json`
