4 Services Description

4.1 What We Provide

Certivo provides motion-based human verification services that:

  • Generate randomized verification challenges for End Users
  • Analyze video responses using computer vision and AI
  • Return trust scores and verification results via API
  • Detect fraudulent activity and bot attacks
  • Provide analytics and reporting dashboards
  • Offer webhook notifications for verification events

4.2 How It Works

  1. Challenge Generation: Your application requests a verification challenge via our API
  2. End User Response: The End User completes the motion-based challenge (e.g., "Turn left")
  3. Video Analysis: Our AI analyzes the video in real-time for liveness and motion
  4. Result Delivery: We return a trust score and pass/fail result to your application
  5. Decision Making: Your application decides how to proceed based on the result
