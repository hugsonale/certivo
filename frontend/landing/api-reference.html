Authentication

Certivo uses API keys to authenticate requests. Include your API key in the Authorization header with Bearer authentication.

CURL 
curl https://api.certivo.com/v1/challenge \
  -H "Authorization: Bearer YOUR_API_KEY"
JavaScript 
const response = await fetch('https://api.certivo.com/v1/challenge', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
Python 
import requests

headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}

response = requests.get('https://api.certivo.com/v1/challenge', headers=headers)
⚠️ Keep Your API Key Secret
Never expose your API key in client-side code. All API requests must be made from your backend server.
POST /v1/challenge

Creates a new verification challenge for a user. Returns a unique challenge ID and randomized movement instruction.

Request Parameters

Parameter Type Required Description
device_id string Required Unique identifier for the device/browser. Used for tracking and trust scoring.
user_id string Optional Your internal user ID. Helps with analytics and fraud detection.
metadata object Optional Custom metadata to attach to this challenge (max 16 keys, 1KB total).

Example Request

curl -X POST https://api.certivo.com/v1/challenge \

                POST
                /v1/verify
            


            

                Submits a video recording for verification. Certivo analyzes the video in real-time and returns a trust score with liveness detection results.
            


            
Request Parameters

            

                
                    

                        Parameter
                        Type
                        Required
                        Description
                    

                
                
                    

                        challenge_id
                        string
                        Required
                        The challenge ID returned from /v1/challenge
                    

                    

                        token_id
                        string
                        Required
                        The token ID returned from /v1/challenge
                    

                    

                        device_id
                        string
                        Required
                        Same device_id used when creating the challenge
                    

                    

                        video
                        file
                        Required
                        Video file (webm or mp4 format, max 10MB, 3-15 seconds)
                    

                
            


            

                
💡 Video Requirements

                

                    Format: webm or mp4

                    Duration: 3-15 seconds

                    Size: Max 10MB

                    Resolution: Minimum 640x480

                    Frame Rate: Minimum 15fps

                            JavaScript
                            
                        

                        
const formData = new FormData();
formData.append('challenge_id', 'ch_xyz789abc123');
formData.append('token_id', 'tok_def456ghi789');
formData.append('device_id', 'device_abc123');

                            Python
                            
                        

                        
import requests

files = {
    'video': ('verification.webm', open('video.webm', 'rb'), 'video/webm')
}

data = {
    'challenge_id': 'ch_xyz789abc123',
    'token_id': 'tok_def456ghi789',
    'device_id': 'device_abc123'
}

response = requests.post(
    'https://api.certivo.com/v1/verify',
    headers={'Authorization': 'Bearer YOUR_API_KEY'},
    files=files,
    data=data
)

result = response.json()

if result['challenge_passed']:
    print(f"✓ Human verified! Trust score: {result['trust_score']}")
else:
    print(f"✗ Verification failed: {result['error']}")

Error Codes

            

                Certivo uses conventional HTTP status codes and detailed error messages.
            


            

                
                    

                        Code
                        HTTP Status
                        Description
                    

                
                
                    

                        INVALID_API_KEY
                        401
                        API key is invalid or missing
                    

                    

                        INVALID_CHALLENGE
                        404
                        Challenge ID not found or expired
                    

                    

                        VIDEO_TOO_LARGE
                        400
                        Video exceeds 10MB size limit
                    

                    

                        NO_FACE_DETECTED
                        200
                        No face found in video
                    

                    

                        MOVEMENT_NOT_DETECTED
                        200
                        Expected movement not performed
                    

                    

                        VIDEO_INTEGRITY_FAILED
                        200
                        Video appears fake or manipulated
                    

                    

                        RATE_LIMIT_EXCEEDED
                        429
                        Too many requests
                    

                
            

        


        
        

            
Webhooks

            

                Certivo can send webhook events to notify your application when verifications complete. Configure webhooks in your dashboard.
            


            

                
🔔 Webhook Events

                

                    verification.completed - Sent when a verification succeeds

                    verification.failed - Sent when a verification fails

                    device.flagged - Sent when a device is flagged as suspicious
                

            


            
Webhook Payload Example

            

                

                    JSON
                    
                

                
{
  "event": "verification.completed",
  "timestamp": "2026-03-20T20:15:30Z",
  "data": {
    "session_id": "sess_ghi789jkl012",
    "challenge_id": "ch_xyz789abc123",
    "device_id": "device_abc123",
    "user_id": "user_456",
    "challenge_passed": true,
